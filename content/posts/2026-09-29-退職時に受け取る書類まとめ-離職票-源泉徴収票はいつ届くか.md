「離職票がまだ届かないんですけど、これって普通ですか?」——退職後にそんな不安を検索する人は少なくありません。転職エージェントを利用し複数社から内定を得た経験のある運営者itti(私)が、退職後に必ず必要になる書類を整理して解説します。

この記事でわかること。

- 離職票・源泉徴収票・雇用保険被保険者証がいつ届くかの目安期間
- 書類が届かない・遅れているときに誰へ・どの順番で相談すればいいか
- 転職先が決まっている人／決まっていない人で優先すべき書類の違い

退職の事務手続きは一生のうちに何度も経験するものではないので、順を追ってわかりやすく整理していきます。

## 退職時に会社から受け取る書類一覧

退職日に手渡しされる書類と、後日郵送される書類は分けて把握しておくと安心です。「[転職の引き止め（カウンターオファー）にどう対応する](/posts/2026-06-27-転職の引き止め（カウンターオファー）にどう対応する-退職を貫くコツ/)」で退職の意思を固めた後、実際の退職日が近づいたら以下の書類の受け取りを意識しておきましょう。

### 離職証明書・雇用保険被保険者証

{{< mark >}}雇用保険被保険者証{{< /mark >}}は退職日に手渡されるケースが多い書類です。ただし会社が保管しているケースもあり、その場合は後日、源泉徴収票や離職票と一緒に郵送されます。紛失していてもハローワークで再発行できますが、**退職後7年以上経過すると再発行できない**ので注意してください。

### 年金手帳（返却がある場合）

会社が年金手帳を預かっていた場合は、退職時に返却されます。基礎年金番号の確認に使うため、転職先に提出を求められることもあります。

### 健康保険資格喪失証明書

健康保険の切り替え（国民健康保険への加入や家族の扶養に入る手続き）に必要な書類です。転職先が決まっていない場合は特に、早めに市区町村の窓口へ提出しましょう。

{{< box color="gray" title="退職日に受け取れる主な書類" >}}
- 雇用保険被保険者証（会社保管の場合は後日郵送）
- 年金手帳（会社が預かっていた場合のみ）
- 健康保険資格喪失証明書
{{< /box >}}

退職日にまとめて受け取れると思い込んでいると、後で慌てることになりますよね。まずは何がその場で渡されるものかを押さえておきましょう。

{{< point >}}退職日に受け取る書類は雇用保険被保険者証・年金手帳・健康保険資格喪失証明書の3つが中心。{{< /point >}}

### 離職票はいつ届く？

会社には、労働者が離職した日の翌々日から**10日以内**に「雇用保険被保険者資格喪失届」と離職証明書をハローワークへ提出する義務があります（出典：厚生労働省）。そこからハローワークでの処理と郵送が挟まるため、実際に手元へ届くのは退職日から**10日〜2週間程度**（目安14〜16日程度）が一般的です。年末年始や年度末は繁忙期にあたるため、さらに遅れることもあります。

なお、転職先が決まっていて失業給付を使わない場合は、本人が希望しない限り会社に離職票を作成する義務はありません。ただし後から必要になって請求すれば、会社は作成・交付しなければなりません。

### 源泉徴収票はいつ届く？

{{< mark >}}源泉徴収票{{< /mark >}}は、所得税法第226条により会社に交付義務があります。退職者については**退職後1ヶ月以内**に交付するのがルールです（出典：所得税法226条）。たとえば10月15日退職なら、11月15日までに届くのが目安になります。転職先での年末調整、または自分で行う確定申告に必須の書類なので、届いたら大切に保管しておきましょう。

### 住民税の通知書（普通徴収への切り替え）

転職先で特別徴収の引き継ぎ手続きをしない場合、住民税は普通徴収に切り替わります（ようするに、給与天引きではなく納付書で自分で支払う方式です）。この場合の納税通知書は、退職時期にかかわらず**多くの自治体で毎年6月上旬〜中旬に一括送付**されます。つまり秋や冬に退職した人は、通知が届くまで数ヶ月空くことになります。「まだ来ないから手続き漏れかも」と心配しなくて大丈夫です。

{{< box color="blue" title="書類ごとの到着目安" >}}
| 書類名 | 届く目安 | 主な用途 |
|---|---|---|
| 雇用保険被保険者証 | 退職日（会社保管なら後日） | 転職先での雇用保険加入 |
| 離職票 | 退職後10日〜2週間 | 失業保険の受給手続き |
| 源泉徴収票 | 退職後1ヶ月以内 | 年末調整・確定申告 |
| 住民税納税通知書 | 翌年6月上旬〜中旬 | 普通徴収の納付 |
{{< /box >}}

{{< point >}}離職票は10日〜2週間、源泉徴収票は1ヶ月以内が交付の目安。住民税の通知は翌年6月頃と時間差がある。{{< /point >}}

### まず会社の担当部署（人事・総務）に確認する

「催促すると角が立つのでは」と迷う人は多いですが、期限を過ぎている問い合わせは失礼にあたりません。電話かメールで「離職票（または源泉徴収票）の発送状況を確認したい」と伝えるだけで十分です。

私自身、JACリクルートメントを利用した転職活動では面接対策や企業とのやり取りをエージェントに任せられて助かりましたが、退職後の書類手続きは会社・ハローワーク・税務署との直接のやり取りになる話です。転職エージェント経由で退職した人でも、書類の確認・催促は**自分で行う必要がある**と知っておきましょう。

### 一定期間を過ぎても届かない場合はハローワークに相談できる

離職票は、退職から約2週間経っても届かない場合、到着を待たずにハローワークへ相談して構いません。さらに、退職日翌日から数えて**12日間**経過しても届かない場合は、失業給付の「仮手続き」ができる制度もあります。相談時は雇用保険番号かマイナンバーカードを持参するとスムーズです。

### 源泉徴収票が届かない場合の税務署への相談

会社に催促しても源泉徴収票が交付されない場合は、退職した会社の所在地を管轄する税務署に「源泉徴収票不交付の届出書」を提出できます。届出を受けた税務署から会社へ行政指導が行われ、多くの場合すぐに発行されます。

会社に連絡を取りづらい事情がある場合は、退職代行を使うという選択肢もあります。

{{< linkcard "/posts/2026-06-13-退職代行って実際どうなの-弁護士運営と民間業者の違い/" >}}

{{< box color="red" title="会社が交付を怠った場合のリスク" >}}
源泉徴収票の交付義務を怠ると、会社側は所得税法上**1年以下の懲役または50万円以下の罰金**（両罰規定あり）の対象になり得ます。ただし実際に刑事罰まで至るケースは少なく、多くは税務署からの行政指導の段階で解決します。
{{< /box >}}

{{< point >}}離職票は2週間経過でハローワーク、源泉徴収票は1ヶ月経過で会社に催促→応じなければ税務署へ。{{< /point >}}

## 書類ごとの使い道を知っておこう

なぜこれらの書類が必要なのか、目的を知っておくと手続きの優先順位がつけやすくなります。

### 離職票 → 失業保険（基本手当）の受給手続きに必須

転職先が決まっておらず失業保険を受給する場合、離職票はハローワークでの求職申込みに必須です。これがないと受給手続きそのものが始められません。

### 源泉徴収票 → 転職先での年末調整、または自分での確定申告に必須

年内に転職した場合は、前職の源泉徴収票を転職先に提出すれば年末調整に含めてもらえます。年をまたぐ場合や転職先が決まっていない場合は、自分で確定申告をする必要があります。

### 雇用保険被保険者証 → 転職先での雇用保険加入手続きに必要

転職先での雇用保険の加入手続きに必要な書類です。紛失していてもハローワークで再発行できますが、退職後7年を過ぎると再発行できなくなるため、早めの保管を心がけてください。

{{< box color="yellow" title="うっかり注意したいポイント" >}}
- 雇用保険被保険者証は退職後7年経過で再発行不可
- 源泉徴収票を紛失すると確定申告の準備がやり直しになる
- 離職票は失業保険の申請時に原本が必要
{{< /box >}}

「そもそも何が・いつまでに必要なのか分からない」という声もよく聞きますよね。使い道を押さえておけば、優先順位に迷うことはありません。

{{< point >}}離職票は失業保険、源泉徴収票は年末調整・確定申告、雇用保険被保険者証は転職先の加入手続きに使う。{{< /point >}}

## 転職先の有無で変わる必要書類とは

「[転職エージェントを使わない方がいい人の特徴5つ](/posts/2026-04-18-転職エージェントを使わない方がいい人の特徴5つ-向いていないケースを解説/)」でも触れられている通り、自分で退職・転職の手続きを進める人ほど、書類の優先順位を自分で整理しておく必要があります。

### 転職先が決まっている場合に提出すべき書類

雇用保険被保険者証と源泉徴収票を転職先へ提出すれば、基本的な手続きは完了します。年内転職であれば源泉徴収票は年末調整に使われるため、忘れずに提出しましょう。離職票は失業給付を使わないなら不要ですが、後から必要になるケースもあるため、会社に破棄せず保管してもらうよう伝えておくと安心です。

### 転職先が決まっていない場合（失業保険を受給する場合）の書類

このケースでは離職票が最優先です。届き次第、住所地を管轄するハローワークで求職申込みと合わせて手続きを進めましょう。「[転職して半年で辞めたくなったら](/posts/2026-06-09-転職して半年で辞めたくなったら-円満退職のタイミング/)」で退職のタイミングを検討した人も、実際に退職日が決まったら離職票の到着スケジュールを逆算しておくと安心です。転職活動そのものを本格的に進めたい場合は、エージェントの使い方を確認しておくのもおすすめです。

{{< linkcard "/posts/2026-04-12-転職エージェントの使い方完全ガイド-登録から内定獲得までの流れを解説/" >}}

{{< box color="green" title="転職先の有無別・優先書類" >}}
- 転職先あり → 雇用保険被保険者証・源泉徴収票を提出
- 転職先なし → 離職票を最優先でハローワークへ
{{< /box >}}

自分がどちらのケースに当てはまるかで、優先すべき書類も連絡すべき窓口も変わってきますよね。もちろん人によって状況は異なるので、迷ったら会社かハローワークに確認してみてください。

{{< point >}}転職先が決まっているなら雇用保険被保険者証と源泉徴収票、決まっていないなら離職票を最優先で確認する。{{< /point >}}

## まとめ｜退職書類チェックリスト

退職後に受け取る書類は、届くタイミングも相談先もそれぞれ違います。離職票は10日〜2週間、源泉徴収票は1ヶ月以内が目安で、遅れている場合は会社→ハローワークまたは税務署の順に相談すれば大丈夫です。

まずは自分の退職日から逆算して、いつ何が届くはずかをメモしておきましょう。転職先が決まっている人もまだの人も、優先すべき書類さえ分かれば手続きに迷うことはありません。初めての退職事務は不安も多いと思いますが、ひとつずつ確認していけば必ず片付きます。

{{< box color="cream" title="退職書類チェックリスト" >}}
- 雇用保険被保険者証・健康保険資格喪失証明書を受け取ったか
- 離職票（必要な場合）が退職後2週間以内に届いたか
- 源泉徴収票が退職後1ヶ月以内に届いたか
- 転職先へ提出すべき書類を出し終えたか
{{< /box >}}
