「内定承諾書にサインしたら、もう後戻りできないんですよね……」

目の前の書類にペンを構えたまま、手が止まっていませんか。エージェントを利用して複数社から内定を得た経験のある運営者ittiが、実体験を交えて解説します。この記事を読むと、次のことが分かります。

- サインする前に確認すべきポイントが具体的に分かる
- 記載内容に疑問があるときの伝え方が分かる
- サイン後でも撤回できるのか、法的な考え方が分かる

不安を煽るのではなく、正しい知識で安心して次の一歩を踏み出せるよう、わかりやすく整理していきます。

## 内定承諾書とは何か｜サインする意味を正しく理解する

内定承諾書を前にすると、「これは絶対に破れない契約書なのでは」と身構えてしまいますよね。まずはこの書類が何を意味するのか、正しく理解しておきましょう。

結論から言うと、内定は法律上「始期付解約権留保付労働契約」として扱われます。**入社日を始期として、一定の理由があれば会社側・労働者側どちらからも解約できる権利を留保した労働契約**、という意味です（大日本印刷事件・最高裁判例が基礎）。

つまり、内定承諾書にサインする時点で、すでに労働契約自体は成立しているケースがほとんどです。サインは「契約をゼロから始めるスイッチ」ではなく、「すでに成立している契約の内容を、双方であらためて確認する手続き」に近いと考えると、身構えすぎずに済みます。

{{< box color="gray" title="内定承諾書とは" >}}
- 労働契約はすでに成立していることを確認する書類
- 「始期付解約権留保付労働契約」＝入社日を始まりとして、一定の理由があれば解約できる契約
- サイン＝契約の開始ではなく、契約内容の確認手続き
{{< /box >}}

### 内定承諾書と労働条件通知書・雇用契約書との違い

似た書類が同時期に何枚も届くため、混同しやすいところです。

- {{< mark >}}労働条件通知書{{< /mark >}}：給与・勤務地・労働時間など、労働基準法で明示が義務づけられた条件を書面で伝えるもの
- {{< mark >}}内定承諾書{{< /mark >}}：入社の意思を会社に伝えるための書類。会社によって様式はまちまち
- {{< mark >}}雇用契約書{{< /mark >}}：労働条件通知書の内容を契約として取り交わす書類（労働条件通知書と一体化している会社も多い）

この3つは役割が違うだけで、上下関係があるわけではありません。**内定承諾書にサインする前に、労働条件通知書の内容と食い違いがないかを照らし合わせる**のが本来の順序です。

### サインすると法的に何が成立するのか

先ほど触れた通り、内定承諾書へのサインそのものが契約の始まりというわけではありません。ただし実務上は、サインをもって「入社の意思が確定した」と会社側に受け取られる場面が多いのも事実です。

だからこそ、サインする前の確認作業には意味があります。契約内容の確認を怠ったまま進めてしまうと、後から「言った・言わない」の水掛け論になりやすいからです。

実際、求人票や口頭説明と実際の労働条件が食い違っていた事案では、会社側の労働条件明示義務違反・信義則違反による損害賠償責任が認められた判例もあります（東京高判H12.4.19）。「口頭で説明された条件」は、書面に残っていなければ後で争いになりやすいと覚えておいてください。

{{< point >}}内定承諾書へのサインは契約の開始ではなく確認手続き。だからこそサイン前の照合が重要になる。{{< /point >}}

### 給与・手当・賞与の記載が口頭説明と一致しているか

面接やエージェントとの面談で聞いていた金額と、書面上の金額が一致しているか。まずここを確認してください。

「基本給に含まれる手当」「みなし残業代の有無」「賞与の算定方法」は、実際の手取り額に大きく影響します。もちろん会社の業績次第で変動する部分もありますが、少なくとも書面上の記載が口頭説明と食い違っていないかは、サイン前に必ずチェックすべきポイントです。

{{< box color="yellow" title="給与確認でよくある見落とし" >}}
- 「基本給」に固定残業代が含まれているかどうか
- 賞与が「業績連動」なのか「固定」なのかの記載
- 交通費・住宅手当など諸手当の支給条件
{{< /box >}}

### 就業場所・職種・勤務時間・休日の明記

「転勤なし」「〇〇職での採用」と聞いていたのに、書面には明記がない、というケースも見られます。特に転勤の有無・職種限定の有無は、後から生活設計に直結する部分なので確認しておきたいところです。

労働条件通知書には就業場所・従事すべき業務の内容を明示する義務があります。記載が曖昧な場合は、次のセクションで紹介する方法で確認しましょう。

### 試用期間の条件（期間・給与差・本採用の基準）

試用期間中は給与が下がる会社も一定数あります。**期間の長さ・給与差の有無・本採用の判断基準**の3点は、事前に把握しておきたいポイントです。

「本採用の基準が曖昧なまま」というケースも珍しくありません。何を満たせば本採用になるのか、具体的な基準が書かれているかを確認してください。

### 「誓約書」「身元保証書」など同時提出書類の中身

内定承諾書と一緒に、誓約書や身元保証書の提出を求められることがあります。ここで意外と見落とされがちなのが、身元保証書の「極度額」です。

2020年4月の改正民法により、身元保証契約は保証人の**賠償責任の上限額（極度額）を明記しなければ契約自体が無効**になります（出典：改正民法・身元保証契約に関する規定）。極度額の記載がない身元保証書を渡された場合は、その場で確認して問題ありません。

また、研修費用返還特約のような特殊な条項が別書類に紛れていることもあります。同封された書類には一通り目を通しておきましょう。

{{< point >}}給与・就業条件・試用期間・同封書類の4点は、サイン前に必ず照らし合わせておきたい。{{< /point >}}

### エージェント経由／直接応募での確認の仕方・例文

確認ルートは、応募経路によって変わります。

- {{< mark >}}エージェント経由{{< /mark >}}：担当アドバイザーに確認を依頼するのが基本ルート。企業への直接連絡よりハードルが低い
- {{< mark >}}直接応募{{< /mark >}}：人事担当者に自分で問い合わせる必要がある

{{< box color="green" title="エージェント担当者への確認例文" >}}
「内定承諾書を拝見したのですが、面談時にうかがっていた〇〇の条件と記載内容に相違があるように見えました。念のため企業様にご確認いただくことは可能でしょうか。」
{{< /box >}}

{{< box color="green" title="人事担当者への確認例文（直接応募）" >}}
「この度は内定のご連絡をありがとうございます。内定承諾書を拝見した際、面接時にご説明いただいた〇〇の内容と記載が異なっているように見えましたので、念のため確認させていただけますでしょうか。」
{{< /box >}}

エージェント経由であれば、こうしたやり取りの代行に慣れている担当者が多く、間に立ってもらえる分だけ切り出しやすくなります。私自身、在職中に活動していたときも、条件面のやり取りはすべてエージェントが企業との間に入ってくれて、有給を数回使う程度で進められました。言いにくい確認ほど、間に立ってもらう価値があると感じています。ただし担当者によって対応の速さには差があるため、返信が数日ないときは遠慮なく催促して構いません。

### その場でサインを保留してよいのか

疑問点が残ったまま、その場でサインする必要はありません。**確認が取れるまでサインを保留する**のは、まったく問題のない対応です。

「即決しないと不利になるのでは」と不安に思うかもしれませんが、条件確認のための保留を理由に内定が取り消されることは通常考えにくいものです。もし返事にもう少し時間が欲しい場合の伝え方は、[内定を保留したいときの伝え方と例文【角を立てない言い方】](/posts/2026-07-31-内定を保留したい…返事を待ってもらう伝え方と例文/)で詳しく解説しています。

{{< point >}}条件確認は正当な権利。疑問が残るならサインを保留してよい。{{< /point >}}

## 内定承諾書にサインした後でも撤回はできるのか

ここが、この記事でいちばん伝えたい部分です。「サインしたらもう終わり」と思い込んで動けなくなる気持ち、よく分かります。

### 法律上の考え方（民法上は労働者からの退職の自由が原則）

民法第627条では、期間の定めのない雇用契約について、**解約の申し入れから2週間が経過すれば契約が終了する**と定められています。内定承諾（＝労働契約の成立）後の撤回・辞退についても、法律上はこの規定に基づく整理が基本になります。

つまり、労働者側には契約を解除する権利がもともと認められているということです。「一度サインしたら二度と撤回できない」という考え方は、法的な前提としては正確ではありません。

{{< box color="blue" title="サイン後の撤回に関する法的な整理" >}}
- 内定はサイン前からすでに成立している労働契約
- 民法627条により、労働者側からの解約は原則自由
- 解約申し入れから2週間で契約は終了する
{{< /box >}}

また、前職をすでに退職済みで収入が途絶える不安から、会社側の求人票と異なる条件にやむを得ず署名してしまったようなケースでは、その署名の効力自体が後から否定されることもあります(出典：労働問題弁護士ガイド)。**不利な状況下でのサインが、そのまま最終確定になるわけではない**という点も、安心材料として知っておいてよいでしょう。

### 「損害賠償を請求される」は実際に起こり得るのか

撤回を考えるとき、多くの人が恐れるのが損害賠償です。もちろん人によって状況は異なりますが、実際に損害賠償が認められるのは「著しく信義則に反する態様」で撤回した場合に限られるというのが一般的な整理です。

具体的には、入社直前になって突然音信不通になる、複数回にわたって虚偽の説明を重ねるといった、著しく不誠実なケースが想定されています。誠実に事情を説明したうえでの撤回であれば、損害賠償に発展する可能性は高くありません。

「辞退したら違約金を取られるのでは」という不安の声もよく聞きますが、**労働基準法第16条により、労働契約の不履行について違約金や損害賠償額をあらかじめ定めておく契約自体が禁止**されています。誓約書に「辞退の場合は違約金〇〇円」といった記載があったとしても、その条項自体が無効というのが法律上の整理です。

マイナビ「中途採用状況調査2025年版」によると、2024年の内定辞退率は9.3%で、2023年（9.0%）、2022年（7.9%）から微増傾向が続いています（出典：マイナビ「中途採用状況調査2025年版」）。撤回・辞退自体は、決して珍しい出来事ではないと分かります。

さらに、2024年に「転職ファストパス」（内定辞退者への再応募時の選考優遇措置）を提示したことがある企業は25.0%にのぼり、2025年以降の活用意向がある企業も28.2%にのぼります（出典：マイナビ「中途採用状況調査2025年版」）。**「一度断ったら縁が切れる」という思い込みは、実態と少しずれている**と言えそうです。

### 撤回・辞退を切り出すタイミングと伝え方の基本

撤回を決めたら、できるだけ早く連絡するのが基本です。連絡が遅れるほど会社側の準備が進み、信義則違反と受け取られるリスクも高くなります。

伝える際は、詳しい理由まで踏み込む必要はありません。「熟慮の末、辞退させていただきたい」という程度で十分です。具体的な伝え方・例文は、[内定辞退の伝え方｜エージェント経由・直接応募のマナーと例文](/posts/2026-06-29-内定辞退の伝え方-エージェント経由-直接応募のマナーと例文/)にまとめています。

なお、承諾後に別の会社からオファーが届いて迷っているケースは、[内定承諾後に他社からオファーが届いたら？判断軸と辞退文例を完全解説](/posts/2026-05-24-内定承諾後に他社からオファー…どうすればいい/)で判断軸を整理しています。あわせて確認しておくと安心です。

{{< point >}}撤回は民法上認められた権利。誠実に早く伝えれば、損害賠償に発展するケースはまれ。{{< /point >}}

**サイン前の数分の確認が、入社後の安心につながる**というのは実感として大きいところです。

### 撤回できないと思い込んで我慢して入社した例

もうひとつ多いのが、「サインしたから後戻りできない」と思い込み、条件への疑問を抱えたまま入社してしまうパターンです。実際には民法上、撤回する権利は残っています。**思い込みだけで選択肢を狭めてしまうのはもったいない**ことです。

私自身、動機が「なんとなく今より良くなりたい」と曖昧なまま活動していた時期があり、内定が出ても最後の決断がなかなかできませんでした。ある企業では通常面接から適性検査、工場見学、役員面接、オファー面談まで進んだうえで、最終的に辞退した経験もあります。決断に迷うこと自体は自然なことなので、思い込みだけで我慢を選ばないでほしいと感じています。

{{< box color="red" title="陥りやすい思い込み" >}}
- 「サイン＝絶対に後戻りできない」という誤解
- 「確認したら評価が下がる」という遠慮のしすぎ
- 「一度断ったらもう縁がない」という決めつけ
{{< /box >}}

{{< point >}}確認不足と思い込みが、後悔の二大パターン。どちらも事前の知識で防げる。{{< /point >}}
