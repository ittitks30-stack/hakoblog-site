「え、この書類、前の会社に頼まないと用意できないじゃん…」内定後の提出書類リストを見て固まった人も多いはず。<strong>入社前の提出書類</strong>には、自分では用意できず前職への依頼が必要なものが混ざっている。エージェント経由で複数社から内定を得た経験を持つ運営者ittiが、書類の種類ごとの依頼先と例文、間に合わないときの対処法を整理する。

- 自分で用意できる書類と前職から受け取る書類の違い
- 源泉徴収票・退職証明書を前職に依頼するタイミングと連絡例文
- 書類が間に合わないときの新しい会社への伝え方と相談先

気まずさを感じやすい前職への連絡も、順序と言い方が分かれば落ち着いて進められる。

## 入社前に提出を求められる書類の全体像

内定後に渡される提出書類リストには、性質の異なる書類が一緒に並んでいる。何がどれに当てはまるのか、パッと見ただけでは分かりにくいですよね。「全部自分で用意するもの」だと思い込んで慌てる人が多いが、実際は**3つのグループに分けて考えると整理しやすい**。

### 自分で用意できる基本書類

マイナンバー確認書類、給与振込先届、扶養控除等申告書などは、役所や自分の口座情報があれば用意できる。急いで前職に連絡する必要はない。

### 前職から受け取って提出する書類

一方で{{< mark >}}雇用保険被保険者証・源泉徴収票・基礎年金番号通知書{{< /mark >}}の3つは、前職を経由しないと手に入らないか、前職の情報が必要になる書類だ。ようするに、前の会社が関わっていないと準備が進まない書類、と考えておけばいい。雇用保険被保険者証は次の会社で雇用保険の加入を続けるため、源泉徴収票は今年分の年末調整のため、基礎年金番号通知書は年金の手続きのために使われる。それぞれ用途が違うので、提出書類リストに名前があったら「前職絡みの書類だ」とすぐ気づけるようにしておきたい。ここが今回の記事の本題になる。

### 会社によっては求められる書類

退職証明書や健康保険資格喪失証明書は、入社先によって求められるかどうかが変わる。リストに載っていたら前職への請求が必要になる、と覚えておけば十分だ。

{{< box color="blue" title="3分類のポイント" >}}
- 自分で用意できる書類 → 急がなくてよい
- 前職から受け取る書類 → 依頼のタイミングが重要
- 会社によって必要な書類 → リストにあれば前職へ請求
{{< /box >}}

{{< point >}}提出書類は「自分で用意」「前職から受け取る」「会社による」の3つに分けると、何を急ぐべきかが見えてくる。{{< /point >}}

## 前職への依頼が必要な書類と、依頼のタイミング・伝え方

「前職に連絡するのが気まずい」という声は非常に多い。退職した会社に自分から連絡を取るのは、誰でも腰が重くなるものですよね。

ただし、源泉徴収票・雇用保険被保険者証・退職証明書の発行は、前職にとって<strong>法律で定められた対応業務</strong>にすぎない。個人的なお願いではなく、事務的な手続きとして依頼してよい。

筆者itti自身、JACリクルートメントを通じて複数社から内定を得て、オファー面談(労働条件の提示)まで進んだ経験がある。最終的には動機が曖昧なまま決め切れず辞退したが、オファー面談で入社条件や提出物の話を聞いた瞬間は身構えた。「これは前の会社に頼まないと用意できないものがある」と気づいたからだ。実際に書類をやり取りする段階まで進まなかった人でも、この感覚には共感できるのではないだろうか。

### 在職中（退職前）に依頼しておくと楽な書類

退職が決まった時点で、総務・人事に一声かけておくと後が楽になる。

- 雇用保険被保険者証の保管場所の確認（会社が預かっているケースが多い）
- 源泉徴収票を退職後いつ頃もらえるか、発行予定日の確認
- 退職証明書が必要になりそうなら、退職時にまとめて依頼しておく

在職中ならまだ連絡の心理的ハードルが低い。退職後に改めて連絡するより先手を打つほうが圧倒的に楽だ。

### 源泉徴収票が届かない・再発行してほしいときの連絡例文

源泉徴収票は<strong>所得税法第226条</strong>により、会社に退職後1カ月以内の交付義務がある（出典：所得税法第226条）。未交付のまま放置すると会社側に罰則が科される可能性もあるため、依頼は正当な権利行使だと考えてよい。

{{< box color="gray" title="源泉徴収票の依頼メール例" >}}
件名：源泉徴収票発行のお願い（氏名：〇〇／退職日：〇年〇月〇日）

お世話になっております。
〇年〇月〇日付で退職いたしました〇〇です。
入社先への提出が必要なため、〇年分の源泉徴収票の発行をお願いできますでしょうか。
お送り先は下記の通りです。
（郵送先住所）

お手数をおかけしますが、よろしくお願いいたします。
{{< /box >}}

電話で頼みにくい場合は、このままメールで送れば事務的に済ませられる。

### 退職証明書を前職に発行してもらう場合の頼み方

退職証明書は<strong>労働基準法第22条</strong>に基づき、本人からの請求があれば会社は遅滞なく発行する義務がある（出典：労働基準法第22条）。請求できる期限は退職から2年以内だ。

依頼するときは、会社が記載してよい項目は「本人が請求した事項のみ」という点を押さえておきたい。退職理由などを勝手に書かれる心配はなく、必要な項目だけ指定して依頼すればよい。

{{< point >}}源泉徴収票・退職証明書は前職の法的義務であり、気まずさを感じる必要のない事務的な依頼だ。{{< /point >}}

## 提出が間に合わない・前職と連絡が取りづらいときの対処

「入社書類が間に合いません…」と焦って知恵袋に相談する人は少なくない。気持ちはよく分かりますよね。内定から入社までの期間は平均49.0日（出典：マイナビ「転職動向調査2025年版」）しかない。もちろん人によって差はあるが、前職とのやり取りに手間取るとあっという間に期限が迫ってしまう。

### 新しい会社への正直な伝え方

間に合わないと分かった時点で、できるだけ早く新しい会社の人事に連絡するのが基本だ。隠して提出日を過ぎるより、事前連絡のほうが印象ははるかに良い。

- 遅れている書類名を具体的に伝える
- 前職への依頼状況（いつ依頼したか）を伝える
- 提出できる見込み時期を伝える

「内定取り消しになるのでは」と不安になる人も多いが、きちんと連絡していれば、ほとんどの会社は提出期限を調整してくれる。もちろん会社の対応方針によって差はあるので、早めの相談を心がけたい。

### 前職が対応してくれない場合の相談先

書類ごとに相談先が異なる点は、意外と知られていない。

{{< box color="blue" title="表の見方" >}}
書類の種類ごとに、根拠法と「対応してもらえないときの相談先」をまとめた。
{{< /box >}}

| 書類 | 根拠法 | 相談先（前職が対応しない場合） |
|---|---|---|
| 源泉徴収票 | 所得税法第226条 | 所轄の税務署（「源泉徴収票不交付の届出書」を提出） |
| 雇用保険被保険者証 | 雇用保険法 | 本人がハローワークで再発行可能（会社を介さなくてよい） |
| 退職証明書 | 労働基準法第22条 | 労働基準監督署 |

特に<strong>源泉徴収票は税務署、雇用保険被保険者証はハローワーク</strong>という切り分けは混同されがちなので覚えておきたい。雇用保険被保険者証は本人だけでハローワークに行けば再発行できるため、前職と連絡が取れない場合でも対応できる。窓口で申請する際は本人確認書類・印鑑・退職した会社の名称や所在地が分かるものを持っていくとスムーズだ。窓口申請なら即日発行、郵送や電子申請だと1〜2週間ほどかかる。

源泉徴収票については、会社に依頼しても応じてもらえないことがある。その場合、いきなり税務署に相談するのではなく、まず「このままでは税務署に届出書を出すことになる」と伝えてみてほしい。それだけで対応してもらえるケースも多い。それでも動きがなければ、実際に税務署への届出に進めばよい。

{{< point >}}書類ごとに相談先が違う。源泉徴収票は税務署、雇用保険被保険者証はハローワーク、退職証明書は労基署と覚えておく。{{< /point >}}

## まとめ：入社前チェックリスト

入社前の提出書類は、自分で用意できるものと前職への依頼が必要なものが混在している。源泉徴収票・退職証明書は前職の法的義務であり、雇用保険被保険者証は自分だけでも再発行できる。前職への連絡は気まずく感じても、事務的な依頼として進めてよい。

{{< point >}}前職への依頼は個人的なお願いではなく法律で定められた事務手続きであり、気まずさを感じる必要はない。{{< /point >}}

{{< box color="cream" title="入社前チェックリスト" >}}
- 雇用保険被保険者証の保管場所を確認した
- 源泉徴収票の発行予定日を前職に確認した
- 退職証明書が必要かどうかリストを確認した
- 間に合わない場合は新しい会社にすぐ連絡した
{{< /box >}}

退職前に一声かけておくだけで、入社直前の慌てる場面は大きく減らせる。まずは手元の提出書類リストを見直し、前職への依頼が必要なものから動いてみてほしい。ここまで読んで準備を進めてきたあなたなら、きっと落ち着いて対応できるはずだ。
