## オンライン面談と対面面談の基本的な違い

エージェントとの面談（キャリアカウンセリング）は、企業の採用面接とは違います。あなたの経歴や希望を共有して、合う求人を紹介してもらうための相談の場です。**オンラインか対面かで、評価や紹介される求人が変わるわけではありません。**

| 項目 | オンライン面談 | 対面面談 |
|---|---|---|
| 面談の内容 | 対面と同じ | オンラインと同じ |
| 移動時間 | かからない | オフィスまでの往復が必要 |
| 場所 | 自宅など静かな場所 | エージェントのオフィス |
| 準備するもの | PCかスマホ・イヤホン・書類のデータ | 書類の印刷物（求められた場合） |
| 日程の入れやすさ | 移動がないぶん入れやすい | 移動を含めた時間の確保が必要 |

面談の方法（オンライン・電話・対面）や対応できる時間帯は、エージェントによって違います。夜間や土日に面談したい場合は、登録時や日程調整のときに確認しておきましょう。

{{< point >}}面談の内容はオンラインでも対面でも同じ。違いは「どこで・何を使って話すか」だけ{{< /point >}}

## オンライン面談のメリット・デメリット

{{< box color="green" title="オンライン面談のメリット" >}}
- 移動時間がかからない：自宅などから参加できる
- 日程を入れやすい：仕事の合間や帰宅後にも入れやすい
- 地方在住でも使える：近くに拠点がないエージェントにも相談できる
- 緊張しにくい：慣れた場所のほうがリラックスして話せる人もいる
{{< /box >}}

{{< box color="yellow" title="オンライン面談の注意点" >}}
- 通信が不安定だと途切れることがある
- 表情や身振りが伝わりにくい（カメラ位置と照明で補える）
- 生活音や背景の映り込みに気を配る必要がある

## 対面面談のメリット・デメリット

対面面談の強みは、表情や声のトーンまで伝わりやすいことです。言葉にしにくい事情を話すときは、対面のほうが話しやすいと感じる人もいます。

{{< box color="green" title="対面面談が向いているケース" >}}
- 転職理由が複雑で、言葉だけでは伝えにくい
- 初めての転職で、直接会って話すほうが安心できる
- 近くに拠点があり、移動が苦にならない
{{< /box >}}

{{< box color="yellow" title="対面面談の注意点" >}}
- 移動時間がかかる
- 平日の日中に面談する場合、在職中だと休みを取る必要があることもある
- 近くに拠点がないと、そもそも選びにくい
{{< /box >}}

## 状況別の選び方

### 初回面談はオンライン・対面どちらがいい？

**迷うならオンラインから始めるのがおすすめです。** 初回面談は経歴や希望条件を共有するのが中心なので、オンラインでも十分です。「このエージェントが自分に合うか」を見極める場でもあるため、移動のないオンラインのほうが気軽に試せます。

### 在職中・離職中で変わる選び方

| 状況 | おすすめ | 理由 |
|---|---|---|
| 在職中・休みが取りにくい | オンライン | 仕事の合間や帰宅後に入れやすい |
| 在職中・休みが取れる | どちらでも | 移動時間を準備に充てたいならオンライン |
| 離職中・時間がある | どちらでも | 不安が大きければ対面で安心感を得る |
| 離職中・早く決めたい | オンライン | 日程を早く入れやすい |

### 地方在住・育児中の場合

- 地方在住：近くに拠点がない場合は、オンラインか電話が現実的です
- 育児中：外出しにくい時期でも、自宅から面談できます。子どもが寝ている時間などに入れられるか相談してみましょう

{{< point >}}制約がある人ほどオンラインが便利。制約が少ないなら、話しやすいほうを選べばOK{{< /point >}}

## オンライン面談の前に整えておくこと

オンラインだからといって印象が悪くなることはありません。ただ、話に集中できるよう、次の点を整えておくと安心です。

{{< box color="green" title="オンライン面談の準備チェックリスト" >}}
背景
- 無地の壁やすっきりした棚の前がベスト
- 洗濯物や個人情報が映り込まないようにする

照明・カメラ
- 窓や照明は顔の前側に（逆光にしない）
- カメラは目線の高さに合わせる

音・通信
- イヤホンマイクを使うと聞き取りやすい
- 通信が不安定なら有線LANにする
- 面談の30分前にツールを起動して接続を確認する

手元に用意するもの
- 職務経歴書のデータ（画面で開いておく）
- 希望条件と転職理由のメモ
{{< /box >}}

## よくある質問

**Q. オンラインと対面、どちらが採用されやすいですか？**

エージェントとの面談は採用選考ではないので、どちらを選んでも採用に影響はありません。紹介される求人は、あなたの経歴や希望条件をもとに決まります。

**Q. スマートフォンでもオンライン面談できますか？**

使うツールによってはスマートフォンでも参加できます。画面が小さく書類を見ながら話しにくいので、できればPCがおすすめです。

**Q. 通信が途切れたらどうすればいいですか？**

つなぎ直して再開すれば大丈夫です。スマートフォンを手元に置いておくと、PCの調子が悪いときの予備になります。
