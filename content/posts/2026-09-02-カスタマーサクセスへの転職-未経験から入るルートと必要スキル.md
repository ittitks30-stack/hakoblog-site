「営業も好きだけど、もっとお客さんと長く関わって成果を一緒に喜べる仕事がしたい」——そんな理由から、未経験でもカスタマーサクセスへの転職を考え始める人が増えています。

とはいえ求人票を見比べると「未経験可」と「実務経験必須」が混在していて、どこまで自分が対象なのか分かりにくいのも事実です。転職エージェントを利用して複数社から内定を得た経験のある運営者ittiが、次の3点を中心に具体的に解説します。

- カスタマーサクセスの仕事内容とセールス・サポートとの違い
- サポート職・営業職・未経験直接応募という職歴別の転職ルート
- 未経験でも今日から始められる準備と、入社後に感じやすいギャップ

求人票の言葉に振り回されず、自分の状況に置き換えて判断できるよう、できるだけ具体的にわかりやすく紹介していきます。

## カスタマーサクセスとは？ セールスやサポートとの違い

{{< mark >}}カスタマーサクセス（CS）{{< /mark >}}は、契約後の顧客が自社サービスを使いこなし、成果を出せるよう能動的に支援する職種です。「顧客が困ったら対応する」カスタマーサポートとは異なり、困る前にこちらから働きかける点が大きな違いになります。

セールスが「契約を取る」ことをゴールにするのに対し、CSは「契約後も使い続けてもらい、契約更新・追加契約につなげる」ことが役割です。ようするに、セールスが入口の担当なら、CSは入口から先の伴走担当というイメージです。

企業によって役割の重心は異なり、オンボーディング（導入初期の定着支援）専任のところもあれば、営業寄りに数字を追う会社もあります。この役割の幅の広さが、後述する「入社後ギャップ」の原因にもなるので覚えておいてください。

{{< box color="gray" title="CS・セールス・サポートの役割イメージ" >}}
- セールス：契約前の顧客に提案し、契約を獲得する
- カスタマーサクセス：契約後の顧客に伴走し、活用・継続・拡大を支援する
- カスタマーサポート：顧客からの問い合わせに受動的に対応する
{{< /box >}}

「結局サポートと何が違うの？」と感じる方も多いですよね。分かりやすく言うと、サポートは「待つ」仕事、CSは「仕掛ける」仕事だと考えると整理しやすくなります。

{{< point >}}CSは契約後の顧客に能動的に働きかけて成果を出す職種で、企業によって営業寄り・サポート寄りなど役割の重心が異なる。{{< /point >}}

## 未経験でもカスタマーサクセスに転職できる理由

「未経験なのに本当に転職できるの？」と不安になる気持ち、よくわかります。結論から言うと、**未経験からの転職は十分に現実的**です。理由は大きく2つあります。

### 業界的に人材不足で未経験採用の枠がある

パーソルキャリアの調査によると、doda掲載求人のうち「インサイドセールス」「カスタマーサクセス」の求人数は、2019年1月から2022年1月の3年間で約12倍に増加しました（出典：パーソルキャリア「第3回“新しい時代に求められる営業職”に関する調査」2022年発表）。

同調査では、これらの求人のうちテレワーク可能な求人の比率も2019年1月の18.8%から2022年1月には75.1%へと約4倍に伸びています（出典：同上）。

急拡大する職種のため採用が追いつかず、企業側もポテンシャル採用（未経験者を将来性込みで採用すること）に踏み切らざるを得ない状況があります。もちろん企業や求人によって差はありますが、業界全体としては追い風だといえます。

### 前職の経験が「そのまま強み」に変換されやすい職種特性

CSに必須なのは、専門資格ではなく顧客とのコミュニケーション力や課題解決力です。営業職の顧客折衝経験、サポート職のヒアリング力、事務職の社内調整力は、どれもCSの業務にそのまま活きます。

{{< box color="blue" title="前職経験とCS業務の対応イメージ" >}}
- 営業経験 → 顧客との関係構築、提案力
- サポート経験 → ヒアリング力、丁寧な対応力
- 事務経験 → 社内外の調整力、資料作成力
{{< /box >}}

未経験だからといって、ゼロから積み上げる必要はありません。**今の職歴をCS向けに翻訳して伝えられるかどうか**が最初の分かれ目になります。この翻訳の具体的なやり方は、後半の「転職活動の進め方」で詳しく扱います。

{{< point >}}CSは求人が急拡大している職種で、未経験でも前職の顧客対応・調整経験をそのまま強みとして伝えやすい。{{< /point >}}

## 未経験からの転職ルート3パターン

自分の職歴がどのルートに近いか、ここで具体的に確認していきましょう。

### ルート1: カスタマーサポート/コールセンターからのステップアップ

サポート職からCSを目指すのは、社内で最も理解を得やすいルートです。顧客対応の基礎ができている前提があるため、書類選考でも評価されやすい傾向があります。

社内異動という選択肢もありますが、CS専任ポジションが無い会社も多いため、転職して職種を明確に変える方が話が早いケースも珍しくありません。サポート出身者がCSにキャリアアップできるか悩む人は実際に多いですが、受動的な対応力に能動的な提案力を上乗せする意識があれば十分挑戦できます。

### ルート2: 営業職からの転換（顧客折衝力を活かす）

営業経験者は、CS未経験可求人の中でも比較的通過率が高い層です。契約前の折衝経験は、契約後の関係維持にも応用が利くためです。

ただし、数字を追わなくて済むだろうという思い込みで転換すると後悔しがちです。多くのCS職には契約更新率・アップセル（追加契約）といった数字目標があり、**セールスとは違う種類のプレッシャー**が存在します。この点は後の章でも詳しく触れます。

### ルート3: 未経験可求人への直接応募（ベンチャーSaaS企業など）

完全に異業種から挑む場合は、SaaS(Software as a Service、クラウド型ソフトウェア)を提供するベンチャー企業の求人が入口になりやすい傾向があります。事業拡大期の企業ほど人手が足りず、ポテンシャル採用の枠が生まれやすいためです。

「前職の経験、CSでどう評価されるんだろう」と不安な方も、まずは職種不問で募集している求人から探してみると選択肢が広がります。より詳しい探し方は[未経験転職に強いエージェントおすすめ5選](/posts/2026-04-07-未経験転職に強いエージェントおすすめ5選-異業種-異職種への転職を成功させた方法/)でも紹介しています。

{{< box color="cream" title="ルート選びの考え方" >}}
- サポート職 → CSの「対応力」に近い経験があるので土台を活かす
- 営業職 → 「折衝力」を契約後の関係構築に転用する
- 異業種 → SaaS企業のポテンシャル採用枠を狙う
{{< /box >}}

{{< point >}}自分の職歴に応じてルートを選べば、CS未経験転職はどの職歴からでも入口を見つけやすい。{{< /point >}}

### 必須スキル（コミュニケーション、課題発見・解決力、基本的なSaaS/ITリテラシー）

必須スキルはどれも特別な資格が要らないものばかりです。顧客の話を正確に聞き取る力、困りごとの背景を掘り下げる力、そして自社サービスがどんなITの仕組みで動いているかを理解する基礎知識があれば十分にスタートラインに立てます。

### あると有利なスキル（データ分析の基礎、Salesforce等CRM/SFAツール操作経験）

CRM/SFA（顧客管理・営業支援ツール）の操作経験や、契約継続率などの数字を読み解くデータ分析の基礎は、あると評価が上がる要素です。とはいえ必須ではないので、無理に資格取得から始める必要はありません。

### 未経験でも今すぐ始められる準備（Progateやツール系の学習、業界研究の仕方)

何から勉強すればいいか分からないという方も多いですよね。そんな方には、次のような**今日からできる準備**をおすすめします。

1. Progateなどの学習サービスでIT用語やSaaSの基礎に触れる
2. 志望企業のサービスに実際に登録し、使い勝手を体験してみる
3. その企業のプレスリリースや採用ページで事業フェーズを調べる
4. SNSでCS職の現役社員の発信を読み、業務のリアルな粒度を掴む

資格取得よりも、こうした行動で「業界理解への熱意」を示すほうが選考では伝わりやすいです。

{{< box color="cream" title="スキルを伝える際の考え方" >}}
- 必須スキルは資格ではなく、コミュニケーション力・課題発見力で判断される
- あると有利なスキルは「無理に取得」ではなく「経験があれば書く」程度でよい
- 資格よりも、今日からの行動で業界理解の熱意を示すほうが選考では伝わりやすい
{{< /box >}}

{{< point >}}必須スキルは資格不要のコミュニケーション力と課題解決力が中心で、今日からの行動で熱意を示すことができる。{{< /point >}}

### 「経験者優遇」求人にどう挑むか

大手エージェント掲載の求人票を比較すると、「未経験可」と書かれていても、実際には「職種は問わないが何らかの顧客対応・成果創出の経験」が前提になっているケースがほとんどです。一方「経験者優遇」枠は、中堅〜大手顧客への折衝経験など、かなり具体的な実務経験を求めています。

つまり**「未経験可」は誰でも通るという意味ではなく、顧客対応の経験を持つ人向けの間口**だと理解しておくと、応募の的を外しにくくなります。「未経験可と書いてあったのに書類で落ちた」という声、実はよく聞きますよね。そのケースの多くは、この前提となる経験が伝わっていないことが原因です。

### 入社後に感じやすいギャップ（数字責任、対応範囲の広さ）

CSは企業ごとに役割設計が大きく異なる職種です。営業寄りに数字目標を強く追う会社もあれば、オンボーディング専任で数字責任が薄い会社もあります。この違いを理解せずに入社すると、数字目標も追うとは聞いていなかったというギャップを感じやすくなります。

また、1人で複数顧客を同時に担当するマルチタスクの負荷や、自社サービスへの深い理解が求められる点も、想像より業務範囲が広いと感じるポイントです。選考の段階で「この会社のCSは営業寄りか、サポート寄りか」を質問しておくことが、入社後のミスマッチを防ぐ一番の対策になります。

{{< box color="yellow" title="面接で確認しておきたい質問例" >}}
- CSチームに契約更新率やアップセルなどの数値目標はありますか
- 1人あたり何社の顧客を担当していますか
- オンボーディング専任か、営業寄りの役割かどちらに近いですか
{{< /box >}}

{{< point >}}企業ごとにCSの役割設計は大きく異なるため、選考段階で数字責任と対応範囲を確認しておくとミスマッチを防げる。{{< /point >}}

## 未経験からの転職活動を成功させる進め方

### 自己PRで前職経験をCS向けに翻訳する書き方

自己PRで何を書けばいいか分からず手が止まる方も多いですよね。自己PRは「前職で何をしたか」ではなく、「その経験がCSでどう活きるか」を書くことがポイントです。たとえば営業経験なら「新規契約〇件」だけでなく、「契約後のフォローで解約を防いだ経験」があれば、それこそがCSに直結するエピソードになります。

自己PRの具体的な書き方や例文は[転職の自己PRの書き方｜受かる例文と作り方](/posts/2026-05-20-転職の自己prの書き方-エージェントが教える受かる例文と作り方/)でも詳しく解説しているので、あわせて参考にしてください。

## よくある質問

**Q. カスタマーサクセスに転職するのに資格は必要ですか？**
A. 必須の資格はありません。Salesforceなどの認定資格は「あると有利」程度で、なくても選考で不利になるわけではありません。

**Q. 20代後半・30代からでも未経験で転職できますか？**
A. 可能です。ただし求人はベンチャー・SaaS企業に偏りやすく、20代向けの枠が多い傾向はあります。[20代の転職エージェントおすすめ5選](/posts/2026-04-05-20代の転職エージェントおすすめ5選-初めての転職を成功させる選び方/)も参考にしながら、自分の年齢に合う求人を探してみてください。

**Q. カスタマーサクセスは「やめとけ」と言われることがあるのはなぜですか？**
A. 数字責任や対応範囲の広さなど、企業によって想定外の負荷を感じるケースがあるためです。選考段階で役割設計を確認しておけば、こうしたギャップはかなり防げます。

**Q. 事務職からでも挑戦できますか？**
A. 挑戦できます。社内外の調整力や資料作成力は、CSの業務でもそのまま活きる強みです。
