# 入社日の決め方｜交渉できる範囲と逆算スケジュール

「内定はもらったけど、入社日っていつにすればいいんだろう…」

そんな声を何度も聞いてきました。転職エージェントを利用して複数社から内定を得た経験のある運営者ittiが、入社日の**決め方**と交渉できる範囲を解説します。この記事で解決できる悩みは次の3つです。

- 内定から入社日まで、どのくらいの期間を空けられるのか
- 現職の引き継ぎ・有給消化と入社日を逆算してどう調整するか
- 入社日を後ろ倒し・前倒ししたいとき、印象を悪くしない伝え方

法律上のルールと実務上の目安をわかりやすく整理し、そのまま使える例文つきで紹介していきます。

---

## 入社日はいつまでに決めればいい？

「内定通知書に書いてある日付のまま進めていいのか、それとも相談していいのか分からない」という戸惑いはよく分かります。

まず結論からお伝えすると、<strong>内定通知書の入社日は企業側の「希望日」であり、確定した義務ではありません</strong>。ビジネス慣行として交渉の余地があることは広く共有されています（出典：Geekly、マイナビ転職）。

{{< box color="gray" title="内定〜入社日までの一般的な目安" >}}
- 内定から入社までの平均期間は{{< mark >}}49.0日{{< /mark >}}（出典：マイナビ「転職動向調査2025年版」）
- 退職交渉・引き継ぎの時間を踏まえると、1〜3ヶ月、なかでも2〜3ヶ月程度が「妥当」とされるケースが多い
- 企業側が入社日を急ぐ理由は、欠員補充やプロジェクトの都合であることがほとんど
{{< /box >}}

もちろん人によって現職の状況は異なるので、この日数はあくまで目安です。次の章で、自分の場合の入社日をどう逆算するかを見ていきましょう。

{{< point >}}内定通知書の入社日は「希望日」。平均49.0日という目安を踏まえて、自分の状況に合わせて逆算していきましょう。{{< /point >}}

退職意思表示・引き継ぎ・有給消化の3つを、後ろ（入社日）からではなく前（退職意思表示）から積み上げて考えるのがコツです。

### 民法の2週間ルールと就業規則の1〜2ヶ月ルールの違い

就業規則には1ヶ月前に申し出るようにと書いてあるけれど、本当にそんなに前から言わなければいけないのか、という疑問はよく寄せられます。ここは法的根拠と実務上の慣習を分けて理解しておく必要があります。

{{< box color="blue" title="表の見方：法的ラインと実務ラインは別物" >}}
下の表の「法的最低ライン」は民法に基づく最低限の権利、「実務上の推奨ライン」は円満退職のための慣習です。どちらも押さえておくと、退職交渉での立ち位置が明確になります。
{{< /box >}}

| 区分 | 期間の目安 | 根拠・補足 |
|---|---|---|
| 法的最低ライン | 退職意思表示から2週間 | 民法627条1項。会社の承諾は不要（出典：日本の人事部QA） |
| 実務上の推奨ライン | 退職意思表示から1〜2ヶ月 | 就業規則に規定されるケースが多い |
| 引き継ぎ期間の目安 | 2週間〜1ヶ月 | 役職者・専門職は1ヶ月以上のケースも（出典：LHH転職エージェント） |
| 内定〜入社日の平均 | 49.0日 | 出典：マイナビ「転職動向調査2025年版」 |

民法627条は強行法規とされており、就業規則に「1ヶ月前」と書かれていても、労働者側が2週間前の通知で退職すること自体は法的に有効です。ただし円満に進めたいなら、実務上の推奨ラインに沿って早めに動くほうが安心でしょう。

在職中に活動した筆者自身の経験でも、面談や面接の日程調整はすべてエージェントが間に入ってくれたおかげで、<strong>有給を数回使う程度</strong>で選考を進められました。退職意思表示のタイミングさえ見誤らなければ、有給消化を無理に削らなくても間に合わせられるケースは多いはずです。

{{< point >}}法的ライン(2週間)と実務ライン(1〜2ヶ月)は別物。退職意思表示から逆算して入社日候補を考えましょう。{{< /point >}}

## 入社日は交渉できる？通りやすい範囲の目安

「もう少し後ろにしてほしいと言ったら、心証が悪くなるんじゃないか」と遠慮する気持ち、分かります。

ですが結論として、入社日の交渉自体は珍しいことではありません。問題は「どこまでなら通りやすいか」を見誤らないことです。

{{< box color="cyan" title="交渉が難しいケース" >}}
- 欠員補充が急務で、すぐに現場に入ってほしいと言われている
- 繁忙期の直前で、人手が絶対に足りないタイミング
- 他の候補者にも声をかけていて、決定を急いでいる
{{< /box >}}

このようなケースでは、半月程度の調整すら難しいこともあります。逆に「引き継ぎに時間がかかる」「有給消化を挟みたい」という理由であれば、企業側も想定内の申し出として受け止めやすい傾向があります。

エージェント経由で活動した際、希望入社日を伝えたところ、担当コンサルタントが企業側との日程調整をすべて代行してくれました。<strong>直接自分で交渉するより心理的なハードルが下がる</strong>のは、エージェントを使う大きなメリットです。

ただし、日程調整を代行してもらえるのはあくまで交渉の窓口としてであり、入社日を最終的に決めるのは自分自身です。企業側の事情も踏まえたうえで、無理のない着地点を一緒に探る姿勢が大切でしょう。

{{< point >}}半月〜1ヶ月の範囲なら通りやすい。欠員急務や繁忙期直前は難しいと心得ておきましょう。{{< /point >}}

## 入社日を後ろ倒しにしたい時の伝え方・NG例

実際に交渉するとなると、どう伝えれば印象を悪くしないかが一番の悩みどころですよね。ポイントは<strong>理由を簡潔に伝え、代替案とセットで提示すること</strong>です。

{{< box color="green" title="良い例文（直接応募の場合）" >}}
「この度は内定をいただき、誠にありがとうございます。現職の引き継ぎに一定の期間を要するため、可能であれば入社日を○月○日以降にご調整いただくことは可能でしょうか。ご検討のほど、よろしくお願いいたします。」
{{< /box >}}

{{< box color="green" title="良い例文（エージェント経由の場合）" >}}
「引き継ぎと有給消化を考えると、入社日は○月○日以降を希望したいです。企業側への伝え方も含めて相談させてください。」
{{< /box >}}

エージェント経由であれば、上記のように担当者へ希望を伝えるだけで、企業への伝え方や交渉自体を代行してもらえます。

直接応募の場合は、オファー面談やメールで自分から切り出す必要がありますが、理由と代替日をセットで示せば、無理な引き延ばしという印象は与えにくいはずです。

{{< point >}}理由は簡潔に、代替日程とセットで伝える。早い段階での相談がNG回避の最大のコツです。{{< /point >}}

## 逆に早めたい・即日に近い入社を求められたときの対応

「来週から来てほしいと言われて焦った」という声もよく聞きます。その焦り、痛いほどわかりますよね。

欠員補充が急務な企業ほど、早期の入社を求めてくる傾向があります。

{{< box color="yellow" title="即日・早期入社を求められたときの対応" >}}
- まず「対応できる最短日」を自分で計算してから返答する（退職意思表示〜引き継ぎの最短ラインを確認）
- 難しい場合は「〇日であれば対応可能です」と代替日を即座に提示する
- 無理に合わせて退職手続きを急ぐと、引き継ぎ不足でトラブルになりやすいので注意
{{< /box >}}

即日対応が難しいのは当然のことです。無理に合わせようとせず、<strong>現実的な最短ラインを冷静に伝えること</strong>が、結果的に双方にとって良い着地点になります。

{{< point >}}即日入社を求められても、まず自分の最短対応日を計算してから返答しましょう。{{< /point >}}

## 退職日と入社日のすき間で変わる保険料

入社日を決めるときに見落としやすいのが、**前職の退職日との間にすき間ができるかどうか**です。1日でもすき間があると、健康保険と年金の手続きが必要になり、保険料の負担も変わります。

社会保険の資格は**退職日の翌日**に失われます。そして保険料は、**月末の時点でどの制度に入っているか**で決まります。

{{< box color="blue" title="退職日と入社日の組み合わせで起きること" >}}
- **9月30日退職 → 10月1日入社**：すき間なし。手続き不要で、9月分の保険料は前職で天引きされる
- **9月20日退職 → 10月1日入社**：9月末時点でどの会社にも属していないため、**9月分の国民健康保険・国民年金を自分で払う**必要がある
- すき間ができる場合は、**退職日の翌日から14日以内**に市区町村で国民健康保険と国民年金の手続きをする（前職の健康保険を任意継続する方法もある）
{{< /box >}}

つまり、入社日が月初なら、**前職は前月の末日で退職する**と手続きも負担も最小になります。逆に月の途中で辞めて翌月に入社すると、1か月分の国民年金（2026年度は月17,920円）などを自分で納めることになります。

有給休暇の消化で退職日が後ろにずれることもあるので、入社日を交渉するときは**前職の最終出社日ではなく、正式な退職日**で考えてください。

（出典：[日本年金機構「会社を退職したときの国民年金の手続き」](https://www.nenkin.go.jp/service/kokunen/kanyu/20140710-03.html)、[日本年金機構「令和8年度の国民年金保険料」](https://www.nenkin.go.jp/oshirase/taisetu/kojin/2026/202601/0123.html)、[マイナビ転職「退職日はいつが得？」](https://tenshoku.mynavi.jp/knowhow/taishoku/01/)）

{{< point >}}入社日が月初なら前職は前月末で退職する。すき間ができると国保・国民年金の手続きと負担が発生する{{< /point >}}

## 入社日決定でよくある失敗と対策

最後に、入社日にまつわるよくある失敗パターンを見ておきましょう。他人事だと思っていても、案外誰にでも起こり得ることですよね。

{{< box color="red" title="よくある失敗パターン" >}}
- 退職交渉が長引き、想定していた入社日に間に合わなかった
- 有給消化を組み込まずに退職し、結果的に損をした
- 入社日を決めた後で引き継ぎの想定漏れが発覚した
{{< /box >}}

「退職交渉が長引いて入社日に間に合わなかった」というのは、実際にQ&Aサイトでもよく見かける典型的な悩みです（出典：doda Q&A）。

対策はシンプルで、<strong>逆算スケジュールの各ステップに1〜2週間の余裕（バッファ）を持たせておくこと</strong>です。

有給消化についても、退職意思表示のタイミングで申請の可否を確認しておけば、後から「消化できなかった」という事態は避けられます。

{{< point >}}逆算スケジュールには1〜2週間の余裕を持たせる。有給消化は退職意思表示のタイミングで確認しましょう。{{< /point >}}

## まとめ：入社日を決める3ステップチェックリスト

{{< box color="cream" title="入社日を決める3ステップ" >}}
1. 退職意思表示のタイミングを、就業規則を確認したうえで決める
2. 引き継ぎ期間と有給消化の希望日数を洗い出し、逆算する
3. 企業へは理由＋代替日程をセットで、早めに相談する
{{< /box >}}

入社日は、内定通知書に書かれた日付が絶対ではありません。とはいえ、企業にも事情があるため、交渉できる範囲には限度がありますよね。<strong>逆算スケジュールを組み、理由と代替案をセットで伝えること</strong>で、無理なく双方が納得できる入社日にたどり着けるはずです。

まずは自分の現職の状況を整理し、退職意思表示のタイミングから逆算してみてください。焦らず、一つずつ確認していきましょう。
