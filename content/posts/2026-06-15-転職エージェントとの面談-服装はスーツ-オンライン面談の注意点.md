「転職エージェントの面談、服装はスーツじゃないとダメですか？」

結論から言うと、スーツでなくて大丈夫です。エージェントとの面談は採用選考ではないので、**清潔感のあるオフィスカジュアルを基本に考えれば十分です**。金融・コンサルなど堅い業界を志望している場合や、面接練習を兼ねる場合はスーツにしておくと安心です。

エージェント利用経験のある当ブログ運営者ittiが、服装の目安と当日の注意点をわかりやすく解説します。この記事を読むと、次のことがわかります。

- 対面・オンライン別に何を着ればいいか
- 志望業界によって服装を変えるべきか
- Zoom（オンライン）面談でやりがちな失敗の防ぎ方

## 転職エージェントの面談は服装で評価される場ではない

エージェントとの面談（キャリア相談）は、企業の採用担当者と会う「本番面接」とは性質が違います。

### 基本は「清潔感があればOK」

服の種類よりも大切なのは清潔感です。**「アイロンのかかった服・汚れや臭いがない・サイズが合っている」の3点を押さえれば十分です。**

{{< point >}}エージェント面談は選考ではないため、スーツは必須ではない。基準は清潔感{{< /point >}}

## 対面面談の服装【状況別3パターン】

清潔感が基本とはいえ、実際に何を着るかは状況によって変わります。3つのパターンで整理します。

### ① スーツが無難なケース

- 仕事帰りにスーツのまま向かう場合（着替える必要はありません）
- 金融・コンサル・士業など、フォーマルな業界を志望している場合
- 面接対策や模擬面接を兼ねる場合（本番を想定した服装の方が練習になります）
- スーツの方が気持ちが引き締まって話しやすい場合

### ② 私服・オフィスカジュアルでOKなケース

- IT・Web・クリエイター系の企業を志望している場合
- 服装自由と事前に案内されている場合
- 休日に時間を取って参加する場合
- 現職がカジュアルな職場で、普段からスーツを着ない場合

オフィスカジュアルの目安は「ジャケット＋シャツ・ブラウス＋スラックス・チノパン」です。

ジーパンで行っていいか迷う人もいるでしょう。色落ちやダメージのない、きれいめのダークデニムに襟付きのトップスを合わせるなら許容されることが多いですが、迷うならチノパンやスラックスにしておくと安心です。

### ③ 避けたい服装

{{< box color="yellow" title="NGな服装の例" >}}
- ヨレたTシャツ・パーカー・スウェット（カジュアルすぎ）
- 汚れやシワが目立つ服
- サイズが大きすぎる・小さすぎる服
- 強すぎる香水・清潔感のない髪型
- ボロボロのスニーカー・サンダル
{{< /box >}}

「私服OK」の範囲は、TPOをわきまえた大人の私服です。Tシャツ1枚・ダメージデニム・サンダルは、私服OKの面談でも避けましょう。

## 志望業界別の服装の目安

志望業界が決まっている人は、面談を面接本番の練習として使うこともできます。業界ごとの目安は次のとおりです。

| 志望業界 | 面談での服装の目安 | 理由 |
|---|---|---|
| 金融・保険・コンサル | スーツ | 面接本番でもフォーマルが基本。練習を兼ねられる |
| メーカー・製造・インフラ | スーツ〜ジャケット着用 | 堅めの社風の企業も多く、きちんと感が無難 |
| IT・Web・ゲーム | オフィスカジュアル | 私服面接の企業もあり、過度なフォーマルは不要 |
| アパレル・美容 | 自分らしいきれいめの私服 | 服装のセンスも見られやすい業界のため |
| 公務員・士業 | スーツ | フォーマルな服装が基本 |

{{< box color="cyan" title="志望業界が決まっている人向けの使い方" >}}
面接本番で着る予定の服装でエージェント面談に行き、「この格好で問題ないか」を聞いてみる方法があります。担当者は志望先の面接に人を送り出している立場なので、業界の温度感を教えてもらえます。服装で悩む時間そのものを減らせます。
{{< /box >}}

{{< point >}}志望業界が決まっているなら、本番で着る服装で面談に行き、その場で意見をもらうのが効率的{{< /point >}}

### ① 背景は「整理された部屋」か「無地の壁」

{{< box color="blue" title="背景設定のポイント" >}}
- 無地の壁またはすっきりした棚が最適
- バーチャル背景は端末によって輪郭がぼやけるため、できれば実際の部屋を整える方が無難
- 洗濯物・雑然とした棚・個人情報が映り込まないよう注意
{{< /box >}}

### ② 照明は「逆光」にしない

窓を背にして座ると、顔が暗く映ってしまいます。窓や照明は<strong>カメラの前方（顔の前側）</strong>に来るよう配置しましょう。

### ③ カメラは「目線と同じ高さ」に

ノートPCをそのまま机に置くと、カメラが下から見上げる角度になります。PCスタンドや本を重ねて、カメラが目線と同じ高さになるよう調整してください。

### ④ 音声・通信は事前テストを

- Wi-Fiが不安定なら、{{< mark >}}有線LAN接続{{< /mark >}}にしておくと安心
- イヤホンやヘッドセットを使うと音声が聞き取りやすくなる
- 家族の声・テレビの音などが入らない場所を選ぶ
- 面談の30分前にはZoom/Teamsを起動して、アップデートや接続確認を済ませておく

### 服装は上半身だけでいい？

カメラに映るのは基本的に上半身ですが、立ち上がったときなどに全身が映ることもあります。上半身と同じトーンの服装にしておくと安心です。

{{< point >}}オンライン面談は服装より「照明・カメラ位置・音声・事前テスト」の準備が大切{{< /point >}}

## 面談当日の持ち物

対面面談の場合、以下を持参するとスムーズです。

- 職務経歴書（可能であれば印刷して持参）
- 履歴書（エージェントによっては不要な場合あり）
- 手帳やスマホ（日程調整のため）
- 筆記用具とメモ帳

オンライン面談の場合は、{{< mark >}}職務経歴書のデータをPC上で開いておく{{< /mark >}}と、確認しながら話せます。職務経歴書は完成していなくても大丈夫です。今の状態を正直に伝えれば、担当者と一緒に仕上げていけます。
