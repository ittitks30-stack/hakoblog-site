「入社してみたら、思っていた仕事と全然違った……」試用期間中にそう感じて、辞めたい気持ちが強くなっていませんか。逆に「そろそろ本採用拒否されるかも」と不安な方もいるはずです。転職エージェントを利用して複数社から内定を得た経験のある運営者ittiが、法律と実務の両面からわかりやすく整理します。

- 試用期間中に辞めたら経歴に残るのか
- 会社側が試用期間中に解雇できる条件
- 次の転職で不利にならない伝え方

## 試用期間とは？本採用との違いをおさらい

試用期間という言葉は知っていても、法律上どういう扱いなのか意外と知らない方が多いですよね。まずはここを整理しておきましょう。

{{< box color="gray" title="試用期間の法的な位置づけ" >}}
試用期間中の労働契約は「解約権留保付労働契約」と呼ばれる。すでに労働契約は成立しており、会社は限定的な条件のもとでのみ契約を解約（解雇）できる状態にすぎない（出典：厚労省・中央労働委員会 個別労働紛争調整事例「試用期間終了後の本採用拒否」）。
{{< /box >}}

つまり試用期間中でも{{< mark >}}すでに正式な社員として契約している{{< /mark >}}のがポイントです。会社側にとっても「お試し雇用」で自由に切れる期間ではありません。

期間の目安は3ヶ月または6ヶ月とする企業が多く、能力の見極めに時間がかかる場合は延長されるケースもあります。就業規則に延長の根拠があるかは、入社時に確認しておくと安心です。

自己都合か会社都合かで、後述する失業給付や離職票の扱いが変わってきます。

{{< point >}}試用期間中も労働契約は成立しており、会社が自由に解約できるわけではない{{< /point >}}

## 試用期間中に自己都合で辞めたら経歴に残る？

一番気になるのが、この「経歴に残るかどうか」ですよね。結論から言うと、法律上の記載義務と、実務上バレる可能性は分けて考える必要があります。

{{< box color="blue" title="履歴書・職務経歴書の扱い" >}}
在籍した事実がある以上、履歴書には書くのが原則。書かなかった場合、雇用保険や社会保険の加入記録から在籍が発覚し、経歴詐称と受け取られるリスクのほうが大きい。
{{< /box >}}

雇用保険の被保険者資格取得届は、試用期間中の入社であっても提出されます。つまり**短期間でも在籍記録は残る**ため、意図的に隠すのは得策ではありません。

一方で、失業給付については注意が必要です。自己都合退職の場合、原則として離職前2年間に被保険者期間が12ヶ月以上必要になります。試用期間の3ヶ月程度で辞めた場合、この条件を単独では満たさないことが多いです。もちろん前職の在籍期間と通算できるケースもあるので、詳しくはハローワークで確認してください。

面接では「短期離職の理由」を必ず聞かれます。ここで前職の悪口にならない言い方を準備しておくと安心です。

具体的な例文は[退職理由の伝え方｜面接でNGな言い方と好印象な例文集](/posts/2026-05-16-退職理由の伝え方-面接でNGな言い方と好印象な例文集/)でも紹介しているので、あわせて確認しておくと準備がしやすくなります。

{{< point >}}短期在籍でも記録は残るため、隠すより正直に伝えて次に活かすほうが得策{{< /point >}}

## 試用期間中に解雇される条件とは

逆に「会社から切られるかもしれない」という不安を持つ方も少なくありません。分かります、入社直後は評価が気になりますよね。

本採用拒否は法律上「解雇」に該当し、労働契約法16条の解雇規制（客観的合理的理由＋社会通念上相当）が適用されます（出典：厚労省・中央労働委員会 個別労働紛争調整事例「試用期間終了後の本採用拒否」）。会社側が自由に切れるわけではなく、**客観的に合理的な理由**が求められる点は覚えておいてください。

とはいえ通常の解雇よりは広い範囲で解約権行使が認められる、という判例法理（最高裁三菱樹脂事件が土台）もあります。認められやすいケースとされにくいケースを整理しました。

能力不足を理由とする本採用拒否は、試用期間が3〜6ヶ月と短いこともあり、よほど程度が著しくない限り認められにくいとされています（出典：ベンナビ労働問題）。「解雇＝一発アウト」ではなく、会社側にも相応の説明責任があるのです。

{{< box color="red" title="直近の裁判例に見る解雇のハードル" >}}
大阪地裁令和6年1月19日の判決では、試用期間中の解雇が無効と判断された事例がある。会社側が合理的な理由を示せなければ、試用期間中であっても解雇は認められない。
{{< /box >}}

もし解雇を告げられたら、労働基準法22条1項に基づき**解雇理由証明書を書面で請求できます**。不当解雇を疑う場合の初動として押さえておきましょう。

### 入社14日を境に「解雇予告手当」の扱いが変わる

もうひとつ、お金に直結する重要なルールがあります。労働基準法21条により、試用期間中の人は**入社から14日以内であれば、会社は30日前の解雇予告も解雇予告手当の支払いも不要**とされています。

逆に言えば、**14日を超えて働いていれば、通常の解雇と同じく30日前の予告か、30日分以上の平均賃金（解雇予告手当）が必要**です。ここを知らないまま「試用期間中だから仕方ない」と受け入れてしまうと、本来受け取れるはずのお金を取り逃がします。

{{< box color="yellow" title="14日ルールで間違えやすい点" >}}
- 14日は暦日で数える。土日祝や欠勤日も日数に含まれる（4月1日入社なら4月14日までが「14日以内」）
- 14日以内でも「予告なしで解雇できる」だけで、**理由なく解雇できるわけではない**。合理的な理由と社会通念上の相当性は同じように必要
- 14日を超えているのに予告も手当もない場合は、会社側の手続きに問題がある可能性が高い
{{< /box >}}

（出典：労働基準法21条、[解雇予告が不要な従業員とは](https://www.kisoku.jp/kaiko/yokoku2.html)）

{{< point >}}本採用拒否も法律上は解雇であり、会社側にも合理的な理由と説明責任が求められる{{< /point >}}

## 試用期間中に辞める前に確認すべき注意点

辞めると決めた後で「あれを確認しておけばよかった」と後悔したくないですよね。ここを飛ばすと退職後に困りやすいので、落ち着いて見ていきましょう。

{{< box color="green" title="退職前に確認したい3つのこと" >}}
- 退職の意思表示は民法上、原則2週間前でOK（就業規則で1ヶ月前などの定めがある場合は要確認）
- 有給休暇は試用期間中でも法定要件を満たせば取得できる
- 離職票は自己都合・会社都合を問わず、雇用保険被保険者であれば退職後10日以内に交付義務がある
{{< /box >}}

引き止めにあうことも珍しくありません。とはいえ意思が固まっているなら、引き止めに時間を使うより次の準備に時間を使うほうが建設的です。

ここで一つ、筆者itti自身の失敗談を紹介させてください。以前転職活動をした際、「なんとなく今より良くなりたい」という曖昧な動機のまま進めてしまい、いざ内定が出ても決め切れず立ち止まった経験があります。

試用期間中に辞めたいと感じたときも同じで、**「なんとなく合わない」で終わらせず、何が具体的に合わないのかを一度言語化する**ことをおすすめします。人間関係なのか、業務内容なのか、条件なのかによって、次に選ぶべき職場の基準が変わってくるからです。

一人で判断がつかない場合は、早めに転職エージェントに相談するのも手です。相談だけなら費用はかからず、[転職エージェントに「登録だけ」はアリ？](/posts/2026-06-16-転職エージェントに「登録だけ」はアリ-最初だけ利用する人の正しい使い方/)で紹介しているように、情報収集目的だけで利用しても問題ありません。

{{< point >}}辞めたい理由を言語化してから動くと、次の職場選びで同じ失敗を避けやすい{{< /point >}}

## 短期離職を次の転職でマイナスにしないための対策

短期離職があっても、伝え方次第で印象は大きく変わります。ここまで不安だった方も、少し肩の力を抜いて読んでください。

{{< box color="cyan" title="面接で使える伝え方の例" >}}
「入社後に業務内容の詳細を把握する中で、〇〇の分野でより専門性を高めたいと考え、早い段階で判断しました」のように、前職批判ではなく**自分の軸に基づく判断**として伝えると印象が悪化しにくい。
{{< /box >}}

doda やマイナビエージェントなど大手エージェントも、短期離職者向けに職務経歴書の書き方や伝え方をサポートするコンテンツを用意しています。それだけ短期離職の相談自体はよくあることで、過度に恐れる必要はありません。

自分の経歴に不安がある場合、[転職エージェントに嘘はバレる？正直に話すべき範囲と伝え方](/posts/2026-06-28-転職エージェントに経歴の嘘はバレる-正直に伝えるべき範囲と注意点/)も参考になります。筆者itti自身、JACリクルートメントを利用して複数社から内定を得た経験がありますが、担当者に状況を正直に伝えたうえで、企業への説明フォローを任せられたことが心強かったです。

エージェント経由なら、応募者の同意なしに前職確認が行われないよう調整してもらえるケースもあり、直接応募にはない安心材料になります。気になる会社があれば、まずは登録だけしておくと選択肢を広げやすくなります。

**試用期間中の退職は履歴書の職歴に書かなくていい？**
在籍した事実がある以上、書くのが原則です。書かないことで後から加入記録との矛盾が生じるほうがリスクは大きくなります。

**試用期間中でも即日退職できる？**
民法上は原則2週間前の意思表示が必要です。ただし体調不良など特別な事情がある場合は、会社と相談のうえ早められることもあります。

**解雇通知された場合、離職票の扱いはどうなる？**
雇用保険被保険者であれば、自己都合・会社都合を問わず退職後10日以内に離職票が交付されます。会社都合（解雇）扱いになる点は、失業給付の条件面で自己都合より有利に働くケースがあります。

{{< box color="gray" title="離職票についての補足" >}}
離職票の交付義務は試用期間中の退職でも変わらない（出典：マイナビ転職「離職票とは」）。「試用期間だから発行されない」ということはないので、退職後に届かない場合は会社に確認してください。
{{< /box >}}
