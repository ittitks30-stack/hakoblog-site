「求人票では月給23万円と聞いていたのに、契約書を見たら全然違う…」入社後に条件が違うと感じて、このページにたどり着いた方も多いはずです。

転職エージェントを利用して複数社から内定を得た経験のある運営者itti（いってぃ）が、感情的にならず事実を確認する手順から相談窓口まで、わかりやすく整理します。

この記事でわかること

- 給与・勤務地・仕事内容が「聞いていた話」と違うときの確認手順
- 会社への伝え方と、実際に使える質問例文
- 社内で解決しないときに頼れる相談窓口（社内→社外→専門家の順）

## ①「聞いていた話と違う」よくある4パターン

まず知ってほしいのは、この悩みを抱えているのはあなただけではないということです。

ハローワークに寄せられる求人内容と実際の相違に関する苦情・相談は、年間で約4,000件近くにのぼるとされています（出典：厚生労働省関連資料、令和3年度時点）。

もちろん相談件数の数え方は年によって変動しますが、それだけ多くの人が同じ壁にぶつかっているということです。

入社後の「話が違う」は、だいたい次の4パターンに集約されます。

### 給与・残業代・賞与が違った

「月給20〜23万円」「平均22万円」といった求人票や面接時の説明と、実際の契約書の金額が食い違うケースです。

Yahoo!知恵袋にも、求人では月20万円台と聞いていたのに契約書は時給900円表記で、実働ベースで計算すると月給が約15万円程度にしかならなかったという相談が寄せられています。聞いていた額より<strong>約6万円</strong>も低かったことになります。

### 勤務地・転勤の有無が違った

「面接では転勤なしと言われたのに、辞令が出た」という声も少なくありません。エリア限定の説明を受けていたはずが、実は全国転勤ありの雇用区分だった、というケースです。

### 仕事内容・役職が求人票と違った

求人票には「企画職」とあったのに実際は営業アシスト業務だった、管理職候補と聞いていたのに一般職扱いだった、というパターンです。

### 休日・休暇制度が違った

「完全週休2日制」と書かれていたのに実際はシフト制で休みが不定期、有給が取りにくい、といったケースもよくあります。

「まさか自分がこんな目に遭うとは」と思いますよね。ですが、パターンさえ分かれば次にやることは明確です。

{{< box color="gray" title="よくある4パターン" >}}
- 給与・残業代・賞与
- 勤務地・転勤の有無
- 仕事内容・役職
- 休日・休暇制度
{{< /box >}}

{{< point >}}給与・勤務地・仕事内容・休日の4つが、条件相違トラブルの大半を占めます。まず自分がどのパターンに当てはまるかを整理しましょう。{{< /point >}}

### 労働条件通知書・雇用契約書を確認する

まず見るべきは{{< mark >}}労働条件通知書（雇用契約書）{{< /mark >}}です。労働基準法15条1項により、事業主は労働条件を書面で明示する義務があります。

求人票の内容と契約書の内容が異なる場合、実務上は<strong>契約書に書かれた内容が優先される</strong>という整理が一般的です。まずは自分が受け取った書面に何が書いてあるかを、落ち着いて読み返してください。

### 求人票・面接時のメモや記録を集める

求人票のスクリーンショット、面接で使われた資料、エージェント経由なら担当者とのメールやチャットのやり取りも「言った証拠」になります。口頭説明だけだった場合は、いつ・誰から・どう聞いたかをメモに残しておきましょう。

### 実際の労働条件と契約書の食い違いを書き出す

給与・勤務地・仕事内容・休日の4項目について、「聞いていた内容」と「実際の内容」を並べて書き出します。ここまで整理できれば、次に何を確認すべきかが明確になります。

{{< box color="blue" title="確認しておきたい書類" >}}
- 労働条件通知書・雇用契約書
- 求人票（スクリーンショット可）
- 面接時のメモ・資料
- エージェント担当者とのやり取り履歴
{{< /box >}}

{{< point >}}労働条件通知書と契約書の内容が、求人票よりも法的に優先されます。まずは書面を照合し、証拠を集めてから動きましょう。{{< /point >}}

### なぜ感情的にならず事実ベースで聞くべきか

「これって違法なのでは」と感じても、いきなり抗議口調で切り出すと、相手も防御的になり事実確認が進みません。<strong>事実だけを淡々と質問する</strong>ほうが、結果的に早く解決に近づきます。すでに集めた記録をもとに「事実の確認」という体裁で話すのがポイントです。

### 人事・上司に確認する際の例文

以下のような聞き方であれば、相手に圧を与えず事実確認に集中できます。

{{< box color="cream" title="確認の例文" >}}
「入社前にご案内いただいた内容と、契約書の記載に相違があるようなので確認させてください。求人票では〇〇とありましたが、契約書では△△となっています。この部分について、どちらが正しいか教えていただけますか」
{{< /box >}}

人事や上司が「求人票の記載ミス」と説明する場合もあれば、「面接時の口頭説明が不正確だった」というケースもあります。いずれの場合も、その場で結論を急がず「一度持ち帰って検討します」と伝えて構いません。

{{< point >}}事実だけを質問する伝え方を選べば、相手も防御的にならず話が前に進みやすくなります。{{< /point >}}

### 転職エージェント経由で入社した場合

「エージェントに相談していいのか」と迷う方もいますが、紹介した企業と求職者の間で条件相違が起きた場合、エージェントに相談するのは自然なことです。むしろエージェントは企業側に事実確認や是正を働きかける立場にあります。

私自身、転職活動でJACリクルートメントを利用した際は、企業とのやり取りをほぼすべて担当者が代行してくれました。条件面の疑問点も、直接ではなくエージェント経由で確認できる安心感があります。

担当者とのやり取りに不安がある場合や、そもそも担当者の説明自体が不正確だった可能性がある場合は、担当変更を申し出るという選択肢もあります。主要なエージェントは担当変更の依頼にほぼ応じており、数日以内に引き継ぎが行われるのが一般的です。

### 労働基準監督署・総合労働相談コーナー

{{< mark >}}総合労働相談コーナー{{< /mark >}}は労働基準監督署内などを含め、全国379か所に設置されています。相談は無料で、専門の相談員が賃金や労働条件のトラブル全般に対応してくれます（出典：厚生労働省東京労働局公表資料）。

ハローワーク経由で入社した場合は「ハローワーク求人ホットライン」（求職者・就業者専用、<strong>03-6858-8609</strong>、平日8:30〜17:15）という専用窓口もあり、申し出るとハローワークが企業に事実確認・指導を行ってくれます（出典：厚生労働省「確かめよう労働条件」）。

なお職業安定法5条の3では、事業者に労働条件の書面明示義務が課されています。虚偽の条件提示は同法65条10号により罰則の対象になり得ますが、もちろんすべてのケースが違法にあたるわけではなく、単なる記載ミスや説明不足であることも多いので、まずは事実確認から始めるのが安全です。

### 労働組合・ユニオン

会社に労働組合がなくても、一人でも加入できる社外の労働組合（合同労組・ユニオン）があります。相談は無料・秘密厳守が基本です。

団体によっては加入費2,000円・月額組合費2,000円程度で、労働条件の改善交渉まで対応してくれます。解雇だけでなく、条件相違のような待遇面のトラブルも扱ってもらえます。

### 弁護士の無料相談はどう探す？

未払い賃金の請求など、個別の法的な請求を検討する段階になったら弁護士の出番です。多くの法律事務所が労働問題の初回無料相談を実施しています。団体交渉が必要なケースはユニオン、個別の金銭請求は弁護士、というすみ分けで考えると相談先を選びやすくなります。

{{< box color="cyan" title="相談窓口の目安" >}}
| 窓口 | 費用 | 向いているケース |
|---|---|---|
| 転職エージェント | 無料 | 紹介経由の入社で条件相違があった場合 |
| 総合労働相談コーナー | 無料 | まず事実確認・アドバイスがほしい場合 |
| 労働組合・ユニオン | 加入費・月会費が必要な団体もある | 会社との交渉まで動いてほしい場合 |
| 弁護士 | 初回無料相談が多い | 未払い賃金など金銭請求が絡む場合 |
{{< /box >}}

{{< point >}}相談窓口は「社内→公的機関→専門家」の順で広げると、無理なく段階的に対応できます。{{< /point >}}

## ⑤このまま働く？改善しないときの選択肢

確認や相談を尽くしても状況が変わらないこともあります。決断は簡単ではありませんよね。ここでは3つの視点から整理します。

### 我慢して働き続けるリスク

条件相違を我慢したまま働き続けると、モチベーションの低下や心身への負担が蓄積しやすくなります。「泣き寝入りするしかないのか」と思う前に、次の項目で判断基準を確認してください。

### 早期退職・転職を検討する判断基準

私自身、転職活動では「なんとなく今より良くなりたい」という曖昧な動機のまま進めてしまいました。内定が出ても決め切れず、立ち止まった経験があります。

条件相違をきっかけに退職・転職を考えるときも同じです。<strong>「何が譲れないか」を先に言語化しておく</strong>ことが、後悔しない決め手になります。

給与なのか、仕事内容なのか、それとも働き方なのか。軸が曖昧なまま動くと、次の職場でも同じ壁にぶつかりかねません。

### 次の転職で同じ失敗を防ぐための条件確認方法

次に転職する際は、内定承諾前に労働条件通知書の提示を必ず求め、求人票・面接での説明との食い違いがないか照合しておきましょう。エージェント経由であれば、担当者に条件面の再確認を依頼するのも有効です。

{{< box color="yellow" title="次の転職で確認したいこと" >}}
- 内定承諾前に労働条件通知書を必ず確認する
- 給与は「基本給」「みなし残業込み」かを明確にする
- 転勤・異動の有無を書面で確認する
- 気になる点はエージェント担当者に事前に質問しておく
{{< /box >}}

{{< point >}}動機や譲れない条件を言語化しておくことが、退職・転職どちらを選ぶ場合でも後悔を減らします。{{< /point >}}

{{< box color="cream" title="まとめ" >}}
入社後に聞いていた条件と違うと感じたら、まず<strong>確認→記録→相談</strong>の順で落ち着いて動くことが大切です。感情的に動くよりも、事実を積み上げるほうが結果的に早く解決に近づきます。
